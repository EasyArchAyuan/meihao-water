## 2. P0-1：ICP 备案（不做其他都白搭）

**为什么是零号**：百度对已备案站点有显著加权；未备案或备案信息不符的站点，会被限制收录甚至直接不出结果。你们的 `src/data/company.ts` 里仍是：

```ts
icp: "TODO: ICP备案完成后填写",
```

**行动**：
1. 在工信部 / 接入商（腾讯云）发起 ICP 备案，主体用「廊坊市美好商贸有限公司」，域名 `meihaowater.site`（建议以 ASCII 域名为备案主域，IDN 中文域名可一并备案）。
2. 备案通过后，把备案号填入 `src/data/company.ts` 的 `icp` 字段，Footer 会自动展示（已写好 `hasIcp` 逻辑）。
3. 备案号同时利于**百度站长平台**「主体认证」与**百度百科**词条创建。

> 备案期间百度仍可能抓取，但排名权重会受限；备案是百度信任的第一锚点。

## 3. P0-2：百度统计 + 站长平台 + 主动推送

### 3.1 百度统计（百度统计，hm.baidu.com）
当前全站**没有任何统计**。百度统计有两个不可替代作用：
- 在**百度站长平台**做站点验证（文件/CNAME 或统计代码回执）；
- 提供百度流量、来源、落地页真实数据，否则你永远不知道优化有没有用。

**实施（我可做，需你提供「百度统计 ID」如 `xxxxxxx` ）**：
在 `src/app/layout.tsx` 的 `<body>` 内、JSON-LD 脚本之前或之后，加原生脚本：

```tsx
<script async src="https://hm.baidu.com/hm.js?你的统计ID" />
```

### 3.2 百度搜索资源平台（ziyuan.baidu.com）
备案 + 统计就绪后：
1. 添加站点 `https://meihaowater.site`，完成验证；
2. **提交 sitemap**：`https://meihaowater.site/sitemap.xml`（站点已有，直接提交）；
3. 开启「**链接提交 → 主动推送**」，拿到 **接口 token**。

### 3.3 主动推送（加速收录，关键）
百度抓取慢，新文章靠被动抓取可能几周不收。**主动推送**能把 URL 实时推给百度，收录从「周级」降到「小时级」。

**我可实施的自动化**：在 `.github/workflows/content-publish.yml`（已有）末尾加一步，用百度主动推送 API：

```
POST https://push.zhanzhang.baidu.com/urls?site=meihaowater.site&token=你的TOKEN
Body: 每行一个 URL（取自 sitemap 或本次新增文章）
```

把 token 存为 GitHub Secret `BAIDU_PUSH_TOKEN`，CI 构建后自动推送全量 URL（或增量）。
> 这是你们「周更内容自动化」的天然延伸——文章一上线就推给百度，正好解决 GEO 与百度共同的「新内容不被及时发现」问题。

## 4. P1：技术 SEO 百度专项修正

### 4.1 多域名 301 规范化（立即核对）
4 个域名（中文域 + www + meihaowater.site + www）若都返回 200 同内容，百度会当镜像站**分权**。必须：
- 唯一 canonical = `https://meihaowater.site`（代码已对）；
- 其余 3 个域名 + 所有 `www` **301 永久重定向**到 canonical。

**核对动作**：在服务器 `infra/Caddyfile` 确认非 canonical 站点块做了 `redir https://meihaowater.site{uri} permanent`。如缺失，我可改 Caddyfile 走 CI 同步。

### 4.2 移动适配复核
响应式已满足「自适应」。建议在百度站长平台「移动适配」提交「自适应」声明，并真机（iOS/Android 微信内置浏览器）抽查首屏与电话按钮可点。

### 4.3 Meta 标题 / 描述（百度长度口径）
- **标题**：百度 SERP 约展示 **30 汉字**，你们当前标题短（如「美好水业｜廊坊本地饮水服务品牌」≈15 字），**安全，可保留**。
- **描述**：百度约展示 **78 汉字**。当前首页描述约 45 字，建议补充**核心长尾词**且保持自然，例如加入「廊坊送水电话」「家庭桶装水配送」「一次性桶装水」等（不堆砌、不违规）。
- 修改入口统一在 `src/lib/seo.ts` 的 `buildMetadata` 与 `src/data/site.ts` 的 `description`/`keywords`。

### 4.4 结构化数据 → 抢百度「富摘要」
已做的 JSON-LD 百度基本都认。额外可加：
- **FAQPage** 已做 → 争取百度「问答摘要」展现（本地搜索高点击）；
- 给 `/contact`、`/about` 补 `LocalBusiness` 的 `openingHours`/`geo`（若授权填真实经纬，可进百度地图/本地 pack）；
- `sameAs` 当前为空 → **填已认证的抖音/58/公众号主页**（见 §6），帮百度做实体聚合，也从 GEO 维度增强。

## 5. P1：内容策略（百度权重核心）

百度排序里，**原创度 + 更新频率 + 内链 + 用户停留**权重极高。你们已有 `/news` 周更与 `/faq`，方向对，强化如下：

### 5.1 关键词矩阵（中文分词视角）
百度按中文分词召回，需覆盖**同义词 / 地域变体 / 长尾**：
| 类型 | 示例 | 落地 |
|---|---|---|
| 核心词 | 廊坊桶装水、廊坊送水 | 首页/产品页 title+正文 |
| 长尾词 | 廊坊家庭桶装水配送、廊坊一次性桶装水哪买、广阳区送水电话 | /news 文章 + /langfang/[district] |
| 品牌词 | 美好水业怎么样、水邻居饮用天然水 | /about、/shuineighbor、百科 |
| 问答词 | 桶装水和一次性桶装水哪个好、怎么选饮用水 | /faq（已建，扩张） |
| 地域词 | 廊坊开发区送水、燕郊桶装水 | /langfang 区县页 |

### 5.2 区县落地页（防「细雨算法」）
`/langfang/[district]` 共 11 个。**百度细雨算法专门打击 B2B/黄页类「模板化站群 + 标题堆词」**。必须：
- 每个区 **intro / 场景 / 痛点 / FAQ 都不同**（围绕该区真实地标、小区、产业园），不能只换地名；
- 标题不用「廊坊XX桶装水_XX送水_XX水站」式关键词堆砌（清风算法也禁标题党）；
- 正文字数 ≥ 800，含 2 个以上内链（到 /faq、/products、/contact）；
- `src/data/districts.ts` 每区 `note` 已标待核对点 → 按要求补真实信息。

### 5.3 内容频率与内链
- 保持周更（自动化已就位）；每篇含 `BreadcrumbList` + 相关文章内链（已做）；
- 在文章与 FAQ 中自然链向「订水电话 / 配送范围 / 品牌页」，形成权重闭环。
